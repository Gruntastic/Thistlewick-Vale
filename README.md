# The Ember Crown of Thistlewick Vale

A small, original low-poly fantasy MMORPG vertical slice in Unreal Engine 5.8: one zone, one 5-player dungeon, four classes, three gear sets, one mount.

Status: **Phase 0 (design and contracts)**. Build and run instructions arrive with the Unreal project in Phase 1.
